## 运行入口与证据口径

```powershell
# Unity 执行 MonsterSupergroup.NetworkCombat.Editor.LimboStage2Assets.CreateAndBuild
./Tools/Run-LimboReference.ps1 -Role host -Profile stage2 -AutoWalk -RunName stage2-preview
./Tools/Run-LimboReference.ps1 -Role host -Profile stage2 -WaitFor 2 -Port 8120 -AutoWalk -RunName stage2-pair
./Tools/Run-LimboReference.ps1 -Role client -Profile stage2 -Port 8120 -AutoWalk -RunName stage2-pair
# 隔离机制；FixtureEnemy 可选十个已列组合
./Tools/Run-LimboReference.ps1 -Profile stage2-fixture -FixtureEnemy Skeleton0 -RunName stage2-skeleton
# 将原 180 秒 Rusher L 片段整体平移到 1 秒，不是正常连续预览
./Tools/Run-LimboReference.ps1 -Profile stage2-fixture -FixtureMode l-hold -RunName stage2-l-hold
./Tools/Run-LimboReference.ps1 -Profile stage2-fixture -FixtureMode l-kill -RunName stage2-l-kill
```

机制配置会禁用经验拾取倍率、补血、定位、重置并操作暂停／模拟权；78–87 秒开放正常武器，用于击退与死亡检查。低变体配置在 90 秒创建高变体；这是新网络敌人，只有攻击资源可来自现有池，不称为敌人池复用。所有这些操作写入 `stage2-observation.jsonl`，不能作为正常关卡压力结论。

`host-audit.jsonl`／`client-audit.jsonl` 保存出生实际值、生命变化和波次状态；`stage2-observation.jsonl` 分别记录配置、状态边沿、实际碰撞请求、世界几何及首伤至死亡的观测时间。`damage-attempt` 是伤害尝试，须与生命日志关联，不能当成实际扣血。击杀计时订阅现有 Combatant 的生命变化与确认死亡，从首次有效生命下降计算，包含确认传播及帧边界延迟；生命恢复后重新计时。未观察到首伤则明确标记未知，不用出生寿命代替。显式强制攻击清理样本排除在正常击杀用时之外。
