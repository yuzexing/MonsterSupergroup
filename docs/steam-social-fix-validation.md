# Steam 好友邀请修复：实现与验证记录

日期：2026-09-22。Unity：6000.3.21f1。正式 AppID：4886160。

## 实现结果

- 新大厅使用 FriendsOnly；房主与已认证普通成员都发布准备房间的 `connect`。同时检查 Steam 大厅与游戏房间容量，满员、开局、退房及断线时清除；发布失败每五秒重试。
- 游戏内邀请使用 InviteUserToGame，发送统一大厅连接字符串。兼容旧大厅邀请、Rich Presence 加入、Steam 启动参数和运行中的新 URL 参数。
- 接受后直接退房并串行加入，复用现有网络及场景清理。连续请求取最后一个；重复接受不重连；晚到的旧入厅结果退厅清理；三十秒清理超时取消加入。主动退出或退出游戏会清除排队请求。
- 新增中英文切房进度与超时提示，保留五秒邀请间隔、四人上限及原成员重连规则。

已确定的接入缺陷是 Private 大厅、缺少好友加入信息和 Rich Presence 回调，以及已有会话时直接拒绝加入。旧版没有禁止普通成员发送的分支，不能把“非房主提交成功但无通知”直接归因于权限；该现象最终仍须真实三账号对照。
