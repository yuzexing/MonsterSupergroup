# 二、场景功能定位

> **一句话定义：一个阴暗、潮湿、被森林逐渐吞没的林间战场，通过开阔战斗空间、稀疏自然障碍和暖色地标，为多人幸存者提供持续走位与怪潮战斗空间。**
> 
> 

- **叙事作用：** 长期处于无人管理状态、具有怪异生态、存在人工活动残留的边缘林地。

- **玩法作用：** 新手引导的延续，学习采集、合成、潜行躲避基础操作。

- **情绪作用：** 从初入森林的紧张不安，过渡到与自然建立初步信任的舒缓感。

详细描述：该场景定位为 **4 人联机幸存者玩法下的中型共享战斗竞技场**，主要承担**持续刷怪**、**玩家走位、短距离支援、资源拾取和局部事件触发**等核心功能。

场景整体保持较高的可移动面积，**不以复杂探索和路径解谜为主要目标**，而是通过开阔草地区域、泥土道路、局部高草、火炬、木箱和大型植物等环境元素，形成多个容易识别但彼此连通的软区域。玩家在正常战斗过程中可以短暂分散，在不同位置处理怪群和局部事件，同时仍能在数秒内支援队友。

场景设计重点不是建立明确的房间或路线限制，而是为玩家提供连续的战斗空间和多种走位选择。普通敌人以玩家周围动态生成的方式持续制造压力，保证幸存者玩法所需的包围感和紧张感；特殊敌人、精英、运输队、讨伐队等事件则可以依托泥土道路、火炬、补给点等场景节点出现，从而赋予敌人一定的空间来源和世界逻辑。

在多人玩法层面，该场景需要支持“可分可合”的玩家关系。玩家既可以在开阔区域保持一定距离独立清怪，也可以在精英事件、Boss 战或队友受到讨伐时快速集合。

在视觉层面，该场景通过低明度、低饱和的森林环境衬托高亮度的玩家、敌人和技能特效，保证 4 人同时战斗时的画面可读性。地图中的道路、火炬和大型自然地标同时承担方向识别作用，减少玩家在战斗中对小地图的依赖。

## 3\.1 装饰部件

装饰部件主要用于塑造森林氛围、丰富画面层次、强化区域识别和引导玩家移动。除少数大型物件外，大部分装饰部件不应承担碰撞或阻挡功能，避免影响幸存者类游戏的大规模移动与走位。

### 草地地表

草地是场景中占比最大的基础地表，用于建立幽暗森林的整体视觉基调。地表应通过深浅不同的绿色、局部斑驳、踩踏痕迹和少量枯草变化，避免大面积重复感。

草地本身不提供特殊玩法效果，主要作为玩家、敌人和战斗特效的视觉背景。整体明度和饱和度应控制较低，避免与玩家、敌人和技能特效争夺视觉注意力。

![image\.png](图片和附件/image%203.png)

### 泥土道路

泥土道路作为场景中的主要视觉导向元素，以棕褐色与周围深绿色草地形成明显但不过度突出的色彩对比。

道路不作为硬性通行限制，而是通过形状、色彩和宽度变化自然引导玩家移动。道路可设计为弯曲、交叉或局部断裂的形式，形成环形走位路线和场景构图中的视觉导线。

同时，道路也可以在世界观上暗示人类运输、巡逻或旧时活动路线。

![image\.png](图片和附件/image%207.png)

### 低矮杂草

低矮杂草主要分布在草地和道路边缘，用于丰富地表细节和消除空旷区域的重复感。

此类植物应保持较小体积、较低对比度，不设置碰撞。其功能主要是增加场景自然感，而不影响玩家判断移动空间。

![image\.png](图片和附件/image%201.png)

### 高草丛

高草丛作为中等视觉体量的装饰元素，可以成簇分布在地图边缘、道路附近和非核心战斗区域。

高草用于制造局部视觉密度差异，使地图形成“开阔区”和“植被较密集区”的软区分。大部分高草建议不设置实体碰撞，必要时只使用非常有限的阻挡体。

高草的高度不能长期遮挡玩家主体和敌人攻击提示。

![image\.png](图片和附件/image%206.png)

### 蘑菇

蘑菇是场景中具有较强奇幻感的自然装饰，用于强化“怪物领地”或异常森林的视觉特色。

蘑菇可以采用大小不同的组合方式，以小型蘑菇簇作为地表填充，以较大型蘑菇作为局部视觉锚点。

![image\.png](图片和附件/image%2014.png)

### 花朵

粉色、蓝色等小型花朵作为高饱和度的小面积点缀，用于打破大面积深绿色环境的单调感。

花朵主要承担色彩节奏和视觉点缀作用，不设置碰撞，也不作为主要玩法信息来源。其数量和饱和度应受到控制，避免与技能特效产生视觉冲突。

![image\.png](图片和附件/image%205.png)



### 火炬

若部分火炬仅用于视觉装饰，则主要承担暖色光源、方向标记和构图焦点的作用。

火炬应集中布置在道路、旧前哨或人工活动区域附近，通过橙黄色光线与冷绿色环境形成明显冷暖对比。

装饰型火炬不需要玩家操作，但可以作为重要的地图识别点。

![image\.png](图片和附件/image%204.png)

大石头属于具有实体碰撞的中型自然障碍物，用于限制玩家和敌人的直线移动路径，并在开阔竞技场中制造可绕行的局部空间。

## 3\.2 可交互部件

可交互部件是场景中能够直接影响玩家战斗、成长或团队目标的功能性物件。与普通装饰物相比，可交互部件需要具有更高的视觉识别度，并通过造型、特效、动画或小地图标识，让玩家能够在高强度战斗中快速发现并判断其价值。

场景当前主要包含 **怪物雕像、血瓶、经验球** 三类可交互部件。

### 怪物雕像

怪物雕像是场景中的**团队任务节点**，主要用于在持续刷怪的幸存者战斗过程中插入短期团队目标，引导玩家暂时改变当前位置、移动路线或聚散状态。

怪物雕像随机或按规则出现在场景预设节点，并在**右上角小地图中显示明确标识**。玩家可以根据当前战斗情况决定是否前往雕像并触发任务，而不是强制中断正常战斗流程。

激活雕像后，可以随机产生不同类型的短期任务，例如：

- 所有玩家需在雕像范围内存活 **10 秒**；

- 在雕像附近累计击杀 **30 个敌人**；

- 多名玩家同时进入雕像范围并完成**团队激活**；

![image\.png](图片和附件/image%209.png)

### 血瓶

血瓶是场景中的**生命恢复道具**。玩家接触或拾取血瓶后，可以立即恢复一定数量或一定比例的生命值。

由于血瓶在玩家处于低生命状态时具有较高战略价值，因此生成后应在**右上角小地图中显示位置标识**，让玩家能够主动判断：**是否值得冒险离开当前战斗区域前往拾取血瓶**。

血瓶在视觉上需要与普通环境明显区分，可以通过：

- 红色或暗红色液体；

- 高于环境的饱和度；

- 轻微发光；

- 上下浮动；

- 地面投影或粒子效果；

![image\.png](图片和附件/image%2010.png)

### 经验球

经验球是游戏中最基础、最高频的成长型拾取物。敌人死亡后掉落经验球，玩家拾取后增加局内经验值，并推动角色升级和 Build 成长。

经验球属于典型的**即时拾取型交互物**，玩家不需要额外按键操作，进入拾取范围后即可自动获取。

经验球除了提供成长资源外，还承担一个非常重要的战斗节奏作用：**让击杀敌人之后产生“前往危险区域收集收益”的移动需求。**

经验球应具有：

- 明显的高亮颜色；

- 发光或脉冲效果；

- 清晰简单的轮廓；

- 与草地、敌人和技能特效明显不同的视觉语言。

![image\.png](图片和附件/image%2011.png)



视觉和信息优先级：**怪物雕像 ＞ 血瓶 ＞ 经验球**

# 四、场景视觉设计

## 4\.1 美术风格

- 手绘卡通轻奇幻风格，整体偏幽暗森林氛围，使用明显描边、夸张植物造型和低饱和环境色，保证角色、敌人与技能特效的战斗可读性（参考《Nordic Ashes》）

- **视觉基调：** 深色童话 / 怪诞森林 / 轻度压迫感，不追求写实自然，而强调轮廓识别和装饰性。

- 视角： **俯视偏斜 2\.5D**

    1. 地面可见面积较大；

    2. 场景物体具有一定正面高度表现；

    3. 玩家、敌人与环境通过 Y 轴位置进行前后遮挡关系；

    4. 不采用横版游戏的三层视差结构。

## 4\.3 色彩设计原则



#### 环境色“不抢角色”

环境整体：

- 明度低；

- 饱和度偏低；

- 色相集中在绿、灰绿、棕色。

因此角色即使不是特别亮，也能从背景中脱离出来。



#### 高饱和颜色被限制在“小面积”

80%低饱和环境色 \+ 15%中等饱和装饰色 \+ 5%高饱和功能色。
